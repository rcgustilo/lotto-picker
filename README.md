# Lotto Picker

An Android app and home-screen widget for PCSO lotto in the Philippines.

- **Next jackpot draws:** the five jackpot games (6/58, 6/55, 6/49, 6/45, 6/42) sorted by which draws next, each with a countdown and its current jackpot.
- **Latest results:** winning numbers, jackpot and number of jackpot winners for each game, plus 6D, 4D, Swertres (3D) and EZ2 (2D) for 2 PM, 5 PM and 9 PM.
- **Current prize:** if nobody won the last draw, the jackpot rolls over, so the next prize is at least that amount; if someone won, it restarts from the minimum.
- **Weekly schedule:** which games are drawn each day (today highlighted). Jackpot games draw at 9 PM.
- **Lucky picks:** random numbers for any game. Save picks and the app checks them against each new draw, showing how many numbers match.
- **History:** the last three weeks of draws for each game.
- **Widget:** the next jackpot draw, its current prize and last numbers, a 🎲 lucky-pick button and ↻ refresh.

Results are read from public results pages (Inquirer, with GMA News as a backup) when you open the app or tap Refresh. Always confirm with PCSO before claiming a prize. For 18 and older only; play responsibly.

The APK is built by GitHub Actions on every push and published under Releases.
